#   publish-public.sh            builds the export from it
#   publish-health.py            builds the "what SHOULD be public" set to

#   gate_shipped_instructions.py grades exactly what ships and nothing else
#
# The third one is why this file exists. The pathspecs used to be inline in
# publish-public.sh, and gate_shipped_instructions.py already parsed them
# back out of that script with a regex -- two readers of a list written for
# one. Adding a third made a shared file the only honest option, and moving
# it turned that gate red immediately, which is what a gate that fails
# closed on an empty parse is for.
#
# Entries are git pathspecs, applied as `:(exclude)<entry>`, so both readers
# get git's own matching semantics rather than a reimplementation of them.
