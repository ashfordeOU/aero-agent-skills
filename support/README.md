# Support Department

**Purpose:** how users get help — docs, FAQs, troubleshooting.

## Workspace
- `docs/` — user-facing documentation
- `faq/` — common questions + answers
- `tickets/` — support requests + resolutions

## Operating rules
1. Docs answer before questions arrive
2. Every ticket resolution becomes a doc/FAQ entry
3. Plain language: any user can follow

## Inputs
- Product changes (development)
- User questions

## Outputs
- Documentation, FAQ, resolution records
