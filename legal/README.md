# Legal Department

**Purpose:** how we stay legal — licensing, contracts, IP.

## Workspace
- `contracts/` — agreements, terms
- `licenses/` — license compliance for used software
- `ip/` — IP notes, trademarks

## Operating rules
1. Every dependency's license recorded before use
2. Legal-only: no advice beyond our authority — flag for counsel
3. Copyable ≠ ours: MIT/Apache ports documented, GPL/no-license
   = reference only

## Inputs
- New repos/skills (development, research)

## Outputs
- License compliance reports, contract drafts
