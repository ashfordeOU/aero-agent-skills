# People (HR) Department

**Purpose:** who does what — roles, charters, onboarding.

## Workspace
- `roles/` — role definitions + charters
- `onboarding/` — how new members start
- `culture/` — operating principles

## Operating rules
1. Every role has a charter: what it owns, its fence, its failure
   protocol
2. Trust-ladder: authority is earned (prove → skill → specialize →
   automate)
3. One identity, many functions: hats have deliverables + gates

## Inputs
- Company needs (founder)

## Outputs
- Role charters, org view, onboarding path
