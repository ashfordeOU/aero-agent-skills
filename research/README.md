# Research Department

**Purpose:** what we learn — market, competitor, and technical research
feeding every other department.

## Workspace
- `notes/` — raw findings (one file per topic, dated)
- `briefs/` — distilled briefs (decision-ready, cited)

## Operating rules
1. Store-first: every finding filed + indexed, never left in chat
2. Evidence over claims: every brief cites sources; unverified =
   labeled SIMULATION
3. Supersede-not-delete: updated findings supersede, never erase

## Inputs
- Web search / X / GitHub / arXiv drops from the founder
- Competitor monitoring
- Technical deep-dives

## Outputs
- Research briefs → development (build decisions)
- Market signals → marketing (positioning) + finance (pricing)
